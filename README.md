# SS&E 2026-27 Global Games Calendar Prototype

Mobile-first, local-only interactive prototype for coordinating the SS&E Global Games trip. It demonstrates overlapping calendar events, configurable stream categories, event-local time zones, role-aware editing, and realistic fictional sample data.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run typecheck
npm test
npm run build
```

The prototype uses browser local storage only. It does not connect to Microsoft 365, authenticate users, or deploy production services.

## Prototype status

This repository is a product and UX prototype for internal evaluation. Sample
events and emergency information are fictional. It is not an operational source
of truth and must not be used for emergency response, live travel coordination,
or production communications without the required organizational approvals and
backend implementation.
